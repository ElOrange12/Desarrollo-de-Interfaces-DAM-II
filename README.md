# 🖥️ Diseño de Interfaces (DI) - DAM II

![DAM](https://img.shields.io/badge/Ciclo-DAM-blue?style=flat-square)
![Comunitat Valenciana](https://img.shields.io/badge/Currículo-Comunitat_Valenciana-orange?style=flat-square)

Repositorio de proyectos, prácticas y apuntes del módulo **Diseño de Interfaces (DI)**, correspondiente al 2º curso del Ciclo Formativo de Grado Superior en **Desarrollo de Aplicaciones Multiplataforma (DAM)**. 

Los contenidos y resultados de aprendizaje de este repositorio están estructurados de acuerdo con el currículo oficial establecido para la **Comunitat Valenciana** (Decreto 63/2012 del Consell, que desarrolla el Real Decreto 450/2010 a nivel autonómico).

---

## 📚 Resultados de Aprendizaje (RA)

De acuerdo con la normativa vigente, el módulo se centra en conseguir que el alumno alcance los siguientes objetivos:

| RA | Descripción | Estado |
|:---:|---|:---:|
| **RA1** | **Confección de interfaces de usuario** empleando herramientas y editores visuales. | ⏳ Pendiente |
| **RA2** | **Generación de interfaces** a partir de documentos XML (diseño declarativo). | ⏳ Pendiente |
| **RA3** | **Creación de componentes visuales** y controles personalizados para su integración. | ⏳ Pendiente |
| **RA4** | **Diseño de interfaces** evaluando exhaustivamente su **usabilidad** y **accesibilidad**. | ⏳ Pendiente |
| **RA5** | **Confección de manuales** de usuario y sistemas de ayuda integrados en las aplicaciones. | ⏳ Pendiente |
| **RA6** | **Empaquetado y distribución** de aplicaciones, creando instaladores. | ⏳ Pendiente |

## 📂 Estructura del Repositorio

El repositorio está organizado para abarcar las unidades de trabajo del currículo de la Generalitat Valenciana:

*   📁 `UD01_Introduccion_Interfaces/` - Conceptos básicos, tipos de interfaces y arquitecturas.
*   📁 `UD02_Creacion_Interfaces_Visuales/` - Uso de IDEs, editores visuales y manejo de eventos.
*   📁 `UD03_Interfaces_XML/` - Layouts y diseño declarativo (ej. FXML en JavaFX, XML en Android).
*   📁 `UD04_Usabilidad_Accesibilidad/` - Pautas WCAG, experiencia de usuario (UX), y diseño centrado en el usuario (UCD).
*   📁 `UD05_Componentes_Personalizados/` - Creación de controles propios y enlace a datos (Data Binding).
*   📁 `UD06_Documentacion_Ayuda/` - Generación de manuales y tooltips (JavaDoc, Sandcastle, JavaHelp).
*   📁 `UD07_Distribucion_Aplicaciones/` - Creación de instaladores (InnoSetup, jpackage, MSI, empaquetado APK).

## 🛠️ Tecnologías y Herramientas

A lo largo de las distintas unidades se utilizarán diversas tecnologías clave para el desarrollo multiplataforma:

*   **Lenguajes:** Java, C#, Kotlin/XML (Android)
*   **Frameworks/Librerías:** JavaFX, WPF / Windows Forms
*   **Herramientas de Prototipado y UI:** Scene Builder, Figma / Penpot
*   **Entornos de Desarrollo (IDEs):** IntelliJ IDEA, Visual Studio, Android Studio
